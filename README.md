
# Student Assignment Management System

## About the Project
A Full Stack Web Application designed to
manage student assignments and submissions.

## Technologies Used
- HTML
- CSS
- JavaScript
- Node.js
- Express.js
- Database: Update with your database

## Project Structure

- backend/ - Backend application
- frontend/ - Frontend application
- evidence/ - Application screenshots

## Installation

Clone the repository:

git clone https://github.com/R-Karthikeyani/student-assignment-management-system.git

Install backend dependencies:

cd backend
npm install

Install frontend dependencies:

cd ../frontend
npm install
